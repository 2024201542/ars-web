# 汇报类型

## research_talk 研究汇报

适用：课题汇报、论文进展、题目里带「研究」。关键词：研究、论文、课题。
骨架：background → question → literature（可省） → method → finding 两到四页 → discussion → conclusion → limitation 或 outlook（可省）。
权重：背景和问题约占两到三页，方法一到两页，发现占内容页的一半，讨论和结论各一页。
可省略：文献、不足。材料里没有方法时仍留一页，evidence 写「材料不足，需要补充」。
示例章节名：研究背景、研究问题、研究方法、主要发现、讨论与结论。

## defense 毕业答辩

适用：毕业论文答辩。关键词：答辩、毕业论文、学位。
骨架：background 加 significance → question → literature → method → finding 两到四页 → conclusion → limitation 加 outlook。
权重：开场（背景、意义、问题）不超过四页，发现是主体，结论和不足各一页。
可省略：无。文献可以压成一页「已有研究缺什么」。
示例章节名：选题背景、研究问题、文献与不足、研究设计、研究发现、结论与展望。

## proposal 开题报告

适用：开题、选题论证。关键词：开题、选题、研究计划。
骨架：background → significance → literature（现状与不足） → question → method（内容与方法） → innovation → schedule。
权重：文献和问题是重点，进度安排一页即可。没有发现页，不要编结果。
可省略：创新点可以并进方法页，页数紧的时候。
示例章节名：选题背景、研究意义、文献不足、研究问题、研究内容与方法、进度安排。

## paper_report 文献汇报

适用：组会讲一篇论文、读书报告。关键词：组会、读书报告、文献汇报、这篇论文。
骨架：hook（论文信息） → question → method → finding → discussion（优点与不足） → takeaway。
权重：论文的问题、方法和发现各一到两页，最后一页只写对自己工作的启发。
可省略：不写自己的研究计划，除非用户要求。
示例章节名：这篇论文在回答什么、作者怎么做的、主要结果、优点与不足、对我们的启发。

## lecture 讲解

适用：课程、科普、给学生讲。关键词：讲解、课程、介绍、科普、给学生讲、课件。
骨架：hook（问题或案例） → concept → principle → example 两到三页 → misconception 或 comparison → recommendation → summary。
权重：例子多于定义。先给一个具体失败或成功的例子，再给概念。
可省略：常见误区。页数少时把原理和例子合成一章。
示例章节名：从一个例子说起、这个概念指什么、它是怎么起作用的、两个例子、容易搞错的地方、可以怎么做。

## review 综述

适用：研究现状、文献回顾。关键词：综述、研究现状、文献回顾。
骨架：background → method（检索范围，可省） → literature（脉络，宜用 timeline） → comparison（流派对比） → discussion（争议） → outlook → conclusion。
权重：脉络和对比是主体，检索范围最多一页。
可省略：检索范围。
示例章节名：这个问题从哪来、研究脉络、几种做法的差别、还在争什么、接下来可能往哪走。

## survey_report 调研报告

适用：调查、访谈、问卷。关键词：调研、调查、访谈、问卷。
骨架：background → method（对象、方法、样本） → finding 两到四页 → discussion（原因） → recommendation → conclusion。
权重：先交代找了谁、怎么问的，再讲发现。建议要能对上前面的发现。
可省略：无。样本说不清时方法页写「材料不足，需要补充」。
示例章节名：为什么做这次调研、对象与方法、听到了什么、原因、建议。
